# SAGE
This repository provides the official PyTorch implementation of the framework presented in "Semantically-Aware 3D Gaussian Stylization via View-Adaptive Geometric Correction." >
While 3D Gaussian Splatting (3DGS) has significantly advanced real-time rendering, applying artistic style transfer to 3D scenes introduces critical challenges, including multi-view geometric inconsistency, semantic mismatch, and the degradation of high-frequency details.
To overcome these limitations, a unified architecture is introduced that couples semantic awareness with view-consistent geometry correction. The framework utilizes a View-Adaptive Correction Mechanism (VACM) to dynamically rectify Gaussian positions in densely overlapping regions, effectively mitigating pose-dependent flickering. Additionally, a Semantic Guidance Mechanism (SGM) integrates the Segment Anything Model (SAM) with robust feature matching to enforce precise, region-aware stylization, preventing unwanted semantic bleeding. Finally, a patch-wise Local Alignment strategy is employed to preserve fine-grained artistic strokes and structural integrity. Evaluated on standard benchmarks (Tanks & Temples and Mip-NeRF 360), this method establishes leading performance in both visual fidelity and multi-view consistency.
